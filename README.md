One funny line, whole on its own: "I named all my houseplants so I'd care for them better; now I'm just a disappointed father to twelve dying Gregs." The joke turns on the last word — naming the plants was meant to save them, and instead it only gave their owner twelve named children to fail. The program in `main.ts` (Node 22, standard library only) writes that single line, byte-identically on every run, to `entry.txt` in the output directory (`/output`, or `$MAKEFUN_OUTPUT_DIR` anywhere else), clearing only the directory's contents first.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts && cat out/entry.txt
```
